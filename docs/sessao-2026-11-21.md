## 2. Decisões

| #   | Decisão                                                                                                                                                      | Motivo                                                                                                         |
| --- | ------------------------------------------------------------------------------------------------------------------------------------------------------------ | -------------------------------------------------------------------------------------------------------------- |
| D36 | O histórico chega em lotes de 30 por chamada, com a tela repetindo (máx. 500)                                                                                | Cabe no tempo de uma Edge Function e respeita o intervalo entre chamadas à API                                 |
| D37 | Analisador: faixas salvas nas preferências do perfil; limite de sobreposição padrão `ceil(k²/N)`; matriz até 20 jogos                                        | O limite é o que se esperaria ao acaso; acima de 20 jogos a matriz deixa de ser legível                        |
| D38 | Anexo comprimido para WebP de até 1600 px (JPEG se o navegador não gerar WebP); a URL assinada é pedida ao abrir a foto                                      | Foto de 8–12 MB vira algumas centenas de KB; a URL de 60 s não vence com a tela aberta                         |
| D39 | Offline: o cache do TanStack Query vai para o `localStorage` (apostas, concursos, modalidades, notificações) por 7 dias; sai no logout e na troca de usuário | Só leitura do próprio usuário; nada de token nem URL assinada no aparelho                                      |
| D40 | A cópia offline da sessão só é usada **sem rede**                                                                                                            | Com rede ela impedia a releitura do nível `aal2` depois do MFA (admin ficava preso em `/mfa`), achado pelo e2e |
| D41 | Web Share Target (opcional no 11.14) ficou de fora                                                                                                           | O PDF já é escolhido pela tela de importação; fica para quando houver demanda                                  |
| D42 | `eh_ativo`, `eh_admin` e `aal2` foram para o schema `privado`; nenhuma função `public` executável por `anon`                                                 | Saem do `/rest/v1/rpc` (Security Advisor); as políticas continuam iguais                                       |
| D43 | Abertura estática no `index.html` com a marca                                                                                                                | Primeiro paint antes do JS no 4G                                                                               |
